
# WAD Experiments CLI

A command-line tool to download Web Application Development experiments directly from GitHub.

## Usage

### List all experiments
npx wad-experiments-cli list

### Download Experiment 1
npx wad-experiments-cli 1

### Download using experiment name
npx wad-experiments-cli exp1

### Download all experiments
npx wad-experiments-cli all

### Overwrite existing files
npx wad-experiments-cli 1 --force

## Run an experiment

node wad-exp/exp1.js

## Requirements

Node.js 18 or later.
